# 開発報告書：MY GROWTH WORKBOOK（成長ワークブック）

作成日：2026年10月8日

## 1. 実装した機能

**社員**
- メールアドレスとパスワードでのログイン（公開サインアップはなし。アカウントは管理者が発行）
- 教材一覧（カード表示、「◯章 / ◯章 完了」と進捗率、「続きから再開」「ワークを始める」ボタン）
- 教材詳細（章ごとに 未着手・途中・完了 を表示）
- ワーク回答画面（1問ずつ表示、前へ/次へ、大きい文字と入力欄、5種類の回答形式、iPhone の音声入力に対応）
- 入力中の自動保存（約0.8秒ごと）と保存状態の表示。端末にも控えを残すので、通信が途切れてもアプリを閉じても消えない
- 途中再開（前回の質問位置から再開。別の端末でもサーバーから復元）
- 「この章を完了する」（未回答があれば件数を表示して確認）
- 完了済みの章では「過去の回答を見る」「もう一度ワークを行う」を選べる。再挑戦は新しい回答として保存し、過去の回答は消さない
- 回答履歴（教材名・章名・実施日・質問・回答）と、過去と最新の回答を並べて比較する画面
- パスワード変更、ログアウト

**管理者**
- 学習進捗一覧（社員・教材・完了章数・進捗率・状況・最終実施日）と、社員ごとの章別の完了状況
- 社員アカウント管理（発行、氏名変更、パスワード再設定、管理者権限の付与/解除、利用停止/再開）
- 教材の追加・編集・公開/非公開・並べ替え・アーカイブ
- 章の追加・編集・公開/非公開・並べ替え・アーカイブ
- 設問の追加・編集・並べ替え・削除（アーカイブ方式。元に戻せる）、社員側の表示プレビュー
- 教材写真のアップロード（非公開保存。ログインした社内利用者だけが閲覧可能）
- 写真からの設問読み取り（Claude API を使用。読み取った結果は確認・修正してから登録）

**共通**
- 回答本文は本人しか見られない（管理者も不可）。データベースの行レベルセキュリティ（RLS）で制限
- 設問を編集しても、過去の回答履歴は回答した時点の設問のまま残る
- PWA 対応（ホーム画面に追加してアプリのように起動）
- 初期データ：アチーブメント セールススキルアッププログラム 1教材・5章・28問（通常23問＋実行への決意5問）。何度投入しても重複しない
- アプリ名は環境変数で変更できる

## 2. 起動方法

本番では Vercel 上で動きます（手順は README の「本番公開の手順」）。手元で動かす場合：

```bash
supabase start              # ローカルの Supabase を起動（Docker が必要）
npm install
npm run db:reset:local      # DB を初期化し、初期データとテストユーザーを作成
npm run dev                 # http://localhost:3000 を開く
```

## 3. 公開URL

**まだありません。** Supabase と Vercel のアカウント情報がこちらにないため、公開はしていません。下の「本人の操作が必要なこと」を済ませれば、すぐに公開できる状態です。

## 4. 初期管理者の設定方法

Supabase に初期データを入れたあと、次のどちらかで設定します。

- コマンドで設定：`.env.local` に Supabase の URL とキーを書き、
  `npm run user:create -- --email 代表者のメール --password '初期パスワード' --name '氏名' --admin`
- 画面で設定：Supabase の Authentication 画面でユーザーを作り、SQL Editor で
  `update public.profiles set role = 'admin', full_name = '氏名' where email = '代表者のメール';`

社員は自分で管理者になることはできません（データベース側で拒否します）。

## 5. 社員アカウントの追加方法

管理者でログイン →「管理」→「社員」→ 氏名・メールアドレス・初期パスワード（8文字以上）を入れて「アカウントを作成」。
メールアドレスと初期パスワードを本人に伝えてください。

## 6. 新しい教材・章・設問の追加方法

コードの修正は不要です。

1. 「管理」→「教材」
2. 既存の教材を選ぶ（新しい教材なら「教材を追加」で教材名を入力）
3. 「章を追加」で章番号とタイトルを入力（作成直後は非公開）
4. 章の画面で「設問を追加」：回答形式（自由記述 / 指定個数の複数回答 / 2分類 / 複数項目 / 実行への決意）、設問本文、回答欄を設定
5. 内容を確認し、「社員に公開する」にチェックして保存（新しい教材は教材の画面でも公開をオンにする）

章を公開すると、社員の進捗率は新しい総章数で自動的に再計算されます。

## 7. 写真から設問を追加する方法

1. 章の画面の「教材写真」で写真を選び「アップロード」
2. 写真の下の「設問を読み取る」を押す
3. 読み取った設問が一覧で出るので、写真と見比べて修正・除外し、「◯問を登録」
4. 確認して章を公開

「設問を読み取る」には Vercel に `ANTHROPIC_API_KEY` の設定が必要です。未設定の場合は、写真をタップして拡大表示しながら「設問を追加」から手入力します。
iPhone の HEIC 形式の写真は、アップロードと表示はできますが自動読み取りには対応していません（JPEG / PNG / WebP のみ）。

| 項目 | 状況 | 理由 |
|---|---|---|
| 本番公開（Vercel） | 未実施 | Supabase・Vercel の認証情報がないため。手順書と設定は完成済み |

## 一般社員が使い始めるまでの手順

1. 管理者が「管理 → 社員」でアカウントを発行し、メールアドレスと初期パスワードを本人に伝える
2. 社員がスマートフォンで公開URLを開き、ログインする
3. （任意）iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」
4. 「アカウント」画面でパスワードを自分用に変更する
5. ホームの教材カードから「ワークを始める」

## 本人の操作が必要なこと（公開まで）

1. GitHub に空のリポジトリを作る（コードを push するため）
2. Supabase でプロジェクトを作り、「新規ユーザーのサインアップを許可」をオフにする
3. スキーマと初期データを投入し、初期管理者を作る（README の手順2〜3）
4. Vercel にリポジトリをインポートし、環境変数を設定してデプロイする（README の手順4）
5. （任意）写真の自動読み取りを使う場合は Anthropic の API キーを取得し、Vercel に `ANTHROPIC_API_KEY` を設定する

Supabase の URL・キー、Vercel へのアクセスをいただければ、手順2〜4はこちらで進めます。
